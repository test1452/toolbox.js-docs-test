Function: randomInt()

randomInt(min, max): number

Defined in: functions/randomInt.ts:11

Generates a random integer between the given minimum and maximum numbers.

Parameters​

min​

number

The minimum number (if decimal, will be ceiled).

max​

number

The maximum number (if decimal, will be floored).

Returns​

number

The generated integer.

Example​

randomInt(0, 10); // 5
